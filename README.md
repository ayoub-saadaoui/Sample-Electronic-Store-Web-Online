# Voltix — Electronics Store Pro
                      Created by : Ayoub Saadaoui
                      
Voltix is a modern, responsive electronics storefront developed with a Node.js backend. The project combines a polished shopping interface with a secure authentication system designed to demonstrate full-stack web development fundamentals.

**Key Features**
- Responsive electronics storefront.
- User registration, login, and logout.
- Secure password hashing using bcrypt with 12 rounds.
- SQLite-based session management.
- HttpOnly and SameSite session cookies.
- Authentication rate limiting.
- Server-controlled user roles.
- Unsplash-powered product imagery.

**Security & Architecture**

The application follows security-conscious development practices, including hashed passwords, protected session cookies, authentication rate limiting, and server-side role assignment.

**Project Scope**

Voltix is currently a local development starter. Product listings and cart functionality are demo-only. Real payment processing, order management, inventory management, email verification, and production deployment features are not yet implemented.
